## Tujuan Website Ini

Ada beberapa tujuan utama saya membuat website ini:

1. **Menampilkan project yang pernah saya buat**
2. **Menulis artikel tentang hal-hal teknis**
3. **Mendokumentasikan proses belajar**
4. **Membangun personal branding sebagai developer**

Selain itu, website ini juga menjadi semacam **laboratorium pribadi** untuk mencoba berbagai teknologi web.

---

## Teknologi yang Saya Gunakan

Website ini dibuat dengan stack yang cukup sederhana tetapi fleksibel:

- **React + TypeScript**
- **Markdown untuk menulis artikel**
- **GitHub Pages untuk hosting**
- **CSS sederhana tanpa framework besar**

Kenapa memilih Markdown?

Karena Markdown, Saya bisa fokus pada **konten**, bukan pada HTML atau styling.
